# Bikecraft
## Projeto acadêmico do curso de HTML e CSS da Origamid
https://victor-cordeiro.github.io/Bikcraft/


Este projeto é um site completo chamado **Bikcraft**, desenvolvido utilizando HTML e CSS. O objetivo do projeto é demonstrar a criação de um site com múltiplas páginas, utilizando boas práticas de estruturação e estilização.

## Tecnologias Utilizadas
- **HTML5**: Para a estruturação do conteúdo.
- **CSS3**: Para a estilização e layout responsivo.



## Funcionalidades
- Layout estruturado utilizando **HTML semântico**.
- Design responsivo para adaptação em diferentes dispositivos.
- Navegação entre páginas por meio de links e menus.
- Estilização avançada com **flexbox e grid**.

## Como Executar
1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador de sua escolha.
3. Navegue pelo site utilizando os menus disponíveis.
